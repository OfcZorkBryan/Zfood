# Zfood Implementation Plan

> Execução direta nesta conversa, conforme pedido do usuário. Skills: executing-plans, test-driven-development e verification-before-completion.

**Goal:** entregar primeira aplicação local utilizável e versionada no GitHub.
**Architecture:** frontend HTML/CSS/JS, API HTTP e SQLite em Node.js.
**Tech Stack:** Node.js 24.11+, módulos ES, node:test, node:sqlite.

## Review Focus
- Manipulação de preço/cupom/quantidade: testes de checkout.
- Isolamento de pedidos e permissões: testes de dois clientes e admin.
- Status inválidos e pedidos duplicados: testes de transição e idempotência.
- Persistência: reabrir banco em teste.
- Senha, sessão e origem: testes de login inválido, logout e origem externa.

- [x] Interface public/index.html, public/style.css, public/app.js; catálogo, filtros, favoritos, carrinho, cadastro, checkout, pedidos e administração. Verificar por navegador quando disponível.
